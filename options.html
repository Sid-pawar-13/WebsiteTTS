Ollama on macOS — run this before launching Ollama

Open Terminal and run the command below to allow the Chrome extension to connect to Ollama:

launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"

Then fully quit Ollama and launch it again. If Ollama is already running, setting this variable will not update its environment. You may need to repeat this command after logging in again.

How the API test works

WebsiteTTS sends a short “Hi! This is a test.” speech request. The response is checked for valid, non-empty audio. Saving runs this test first; settings are stored only after it succeeds.

API keys are stored locally in Chrome extension storage.
